# WeHaveCPU - Frontend Service

Frontend Client for **WeHaveCPU**, an IT Hardware & Computer Components E-Commerce platform. Developed as part of the **Web Services and Technologies Course (Academic Year 3)**.

### Key Features
- **Dynamic Catalog & Filtering:** Browse and search IT hardware components by category.
- **Cookie-Based Authentication:** Manage session tokens via cookies integrated with Axios (`withCredentials: true`).
- **Cart & Checkout Flow:** Interactive shopping cart management and simulated checkout workflow.
- **Responsive Layout:** Mobile-first, fully responsive UI built with Bootstrap.

---

## 🏛 Architecture & Setup

- **Build System:** Powered by **Vite** for fast HMR development and optimized production builds.
- **API Integration:** Axios instance configured with request/response interceptors and global HTTP error handling (401/403).
- **Session Management:** Secure token persistence utilizing HTTP cookies for cross-origin API requests.
